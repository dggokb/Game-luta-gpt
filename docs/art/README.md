# Registros de super-resolução (SR)

Histórico dos testes e integrações de SR dos sprites. Os scripts de uso único citados
aqui (`tools/sprites/*_sr_batch.py`, `tools/sprites/prepare_p0*_sr.py`) e os workflows
de execução (`p01-all-sr.yml`, `p01-fast-integrate.yml`) foram removidos da branch depois
que os resultados foram integrados. Para reproduzir, recupere-os do histórico:

```sh
git show 1370332:tools/sprites/p02_sr_batch.py
```
